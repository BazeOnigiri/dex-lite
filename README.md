# DEX-lite

A small Digital Employee Experience (DEX) inspired project: an agent collects
technical metrics from workstations, a backend scores each **device**, and an
autonomous engine detects and fixes common issues, silently when safe, with a
human in the loop when not.

> Work in progress (November 2026). Architecture diagram and demo coming soon.

## Principles
- Scores devices, never people.
- Collects technical state only: no keystrokes, mouse, webcam, window titles or URLs.
- Every automated action is whitelisted, risk-levelled and audited.
